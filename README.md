# B站动态管理脚本

帮助B站用户管理个人动态的脚本，支持动态批量删除 / 取关

## 如何安装
将 `Script.js` 里的代码直接复制粘贴到油猴插件的配置里

## 用法

点开自己个人主页，右下角找到动态管理，按自己需求操作即可

运行过程中会出错，过于频繁等，这个是服务器限制，过几分钟再运行即可。
